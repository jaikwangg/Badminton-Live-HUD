## Stage 2: doubles-v2

คลิป 1:57 นาที มือถือแนวตั้ง 540×960 วางหลังคอร์ท กล้องขยับเล็กน้อย ประเภทคู่ · commit `be0e510`

**เพิ่มจาก stage 1**
- คาลิเบรตเฟรมแรกอัตโนมัติจากเส้นคอร์ท (ไม่ต้องคลิกมุม)
- หาคอร์ททุกเฟรม และชดเชยการขยับกล้องจากเพดานและผนัง
- ตามลูกจากจุดสว่างที่เคลื่อนที่ โดยไม่มีโมเดลตามลูก
- ช็อตจากลูกกลับทิศที่ไม้ + เสียง โดยบังคับให้สลับฝั่ง
- ความเร็วออกไม้ (ค่าประมาณ) จากสูตรแรงต้านอากาศ
- รายงานตรวจอัตโนมัติ และไฟล์ `config.json` สำหรับแก้ผลเอง
- HUD 1080×1920 สองแบบ: v2 แผงซ้อนในวิดีโอ, v3 แบบ stat UI (ตัวล่าสุด)

**ผล**

| บอส | ใกล้ | 94% | 71.4 ม. | 3.8 ม./วิ |

## เรื่องที่ต้องให้คนตัดสินก่อนทำ stage 3

ทั้งสอง prototype ทำนอก spec ตามที่ขอ ซึ่งขัดกับ `docs/GOALS.md` 2 ข้อ (agent แก้ goal เองไม่ได้ตาม `AGENTS.md`):

1. **ประเภทคู่** อยู่ใน non-goals แต่คลิปจริงทั้งหมดเป็นประเภทคู่ และ stage 2 พิสูจน์แล้วว่าแยกตัวตน 4 คนได้
   - ตอนนี้ PR #9 ให้ใช้คลิปประเภทคู่ทดสอบการตามลูกได้ชั่วคราว แต่ขอบเขตระบบยังเป็นประเภทเดี่ยว
2. **ค่า "พลังกาย"** อยู่ใน non-goals เพราะไม่ได้วัดจากเซนเซอร์ v2 ยังมีอยู่ ส่วน v3 เอาออกแล้ว

# T08 — Rally state machine + Kalman + สถิติ

**Goal:** แปลงข้อมูลลูก + เสียง + ผู้เล่น เป็น rally, shot และคะแนนที่ระบบแนะนำ
**Owns:** `src/hud/fusion/kalman.py`, `src/hud/fusion/rally_fsm.py`, `src/hud/fusion/stats.py`
**Depends:** S1, T06/T07 (ใช้ message ปลอมทดสอบก่อนได้)

## ทำ
- Kalman สำหรับลูก: ถ้าลูกหายไม่เกิน 10 เฟรมให้เปลี่ยนสถานะเป็น `predicted` ถ้าหายนานกว่านั้นให้เป็น `lost`
- กรองจุดลูกที่กระโดดผิดปกติ: ถ้าความเร็วเกิน `shuttle.max_px_per_s` ให้ใช้ค่าที่ Kalman เดาแทนจุดที่ตรวจเจอ ทำได้ไม่เกิน 3 เฟรมติดกัน ห้ามล้างวิถีลูกทิ้งเพราะพลาดแค่เฟรมเดียว
- `landing_xy_m_est`: ใช้ตำแหน่งในภาพก่อนลูกหายหรือเปลี่ยนทิศ (ลูกใกล้พื้น) แล้วแปลงด้วย homography ระหว่างลูกลอยให้เป็น `null`
- นับ shot: ใช้ทั้งเสียง `hit` และจังหวะที่ลูกเปลี่ยนทิศ (ต้องเกิดใกล้กันไม่เกิน 100ms ถึงจะนับ)
  - shot ต้องสลับฝั่งเสมอ ถ้าได้สองช็อตติดกันฝั่งเดียวกันให้เลือกตัวที่หลักฐานดีกว่า
  - คนตี (`last_shot.by`): ประเภทคู่ให้เลือกคนในฝั่งนั้นที่อยู่ใกล้ลูกที่สุดตอนตี
- state machine ของ rally: IDLE → SERVE → RALLY → END, คำนวณ rally time และจำนวน shot
- ตอนจบ rally ให้ประมาณจุดลูกตกจากตำแหน่งสุดท้าย แล้วส่ง event `point_suggested` (**ห้ามเพิ่มคะแนนเอง** ต้องรอให้คนกดยืนยัน)
- ประมาณความเร็วลูก (`speed_kmh_est`) ด้วยสูตรแรงต้านอากาศ (LESSONS §7, PR #28): v0 = (e^(kD) − 1) / (kT), k = g / 6.8²
  - D = ระยะบนคอร์ทจากคนตีถึงคนที่ตีกลับ, T = เวลาระหว่างสองช็อต
  - รู้ค่าตอนที่มีคนตีกลับ ช็อตล่าสุดจึงยังไม่มีค่า และช็อตสุดท้ายของ rally ไม่มีค่า
  - เป็น `null` ถ้าไม่รู้ตำแหน่งคนตีหรือคนตีกลับ, T อยู่นอกช่วง 0.4–3 วิ หรือ D < 3 ม.
  - เป็นค่าประมาณ ต้องติดป้าย EST. (กล้องตัวเดียวหาตำแหน่งลูกกลางอากาศบนคอร์ทไม่ได้ จึงไม่ใช้ 3–5 เฟรมแรกหลังตีแล้ว)
